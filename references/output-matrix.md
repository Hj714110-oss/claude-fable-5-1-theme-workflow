# Output matrix

| Mode | Strong outputs | Composition bias | Avoid |
|---|---|---|---|
| Noon | research landing, public launch page, KPI/data story, discovery report | calm blue field, clear index, paper evidence pages, restrained data emphasis | cyber gradients, neon dashboards, blue-on-blue low contrast |
| Night | architecture deck, security brief, strategy memo, engineering case study | deep cover/section fields, sparse technical diagrams, high-contrast evidence | pure black body copy, terminal cosplay, glowing neon overload |
| Morning | archive deck, editorial web article, company/person history, case study, white paper | warm paper, dates, narrow reading column, generous rule lines, human narrative | beige-only blandness, fake nostalgia, rounded card grid |

## Recommended recipes

1. `archive-deck`: 6–10 fixed 16:9 slides. Cover → scope/index → timeline → evidence → comparison → conclusion/source.
2. `editorial-web`: full-bleed hero → archive index → narrow reading column → wide media/chart → footnotes/source.
3. `research-dashboard`: use a paper shell and a single mode color for signal; use tables and chart-led compositions, not a wall of KPI cards.
4. `product-brief`: title/position → capability index → system map → proof/limitations → next step.
5. `social-card`: one date, one title, one finding, one source; 4:5 or 1:1, no tiny body copy.
